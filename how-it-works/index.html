How it works

cloud-sessions drives your Claude Code cloud sessions from any Claude Code session, two-way. Each direction uses something you already have.

Start

claude --cloud is run for you in a pseudo-terminal. The trust prompt is surfaced to you and never answered by the mod. The session's title and its https://claude.ai/code/session_… link come back. Starting is limited to repositories on your allowlist and to a daily cap.

Send

claude -p … --cloud <id> --output-format json is your own claude command, with your own login. /cloud-send sends one message per run, so a follow-up goes into the same running session.

Read

Reading and watching use Claude Code's built-in RemoteTrigger tool (get_run_log), which works with your own login and needs no token. Events are shown as data, cleaned of control and bidi characters and capped.

Under the hood the core reads events from GET /v1/code/sessions/<id>/events with a client-side cursor.

Track and list

/cloud-track records sessions started elsewhere (a link, an id, or every https://claude.ai/code/session_… link in a file, deduplicated and validated). /cloud-list shows titles and links.

Standalone reading (optional)

Reading from a plain terminal or another program is optional and off by default. A token from claude setup-token is inference-only: the events endpoint answers 401, which is why reading inside Claude Code goes through RemoteTrigger. The CLI can use a token from the keychain (macOS, Windows) or a private 0600 file, or, only after a terminal-only opt-in (auth use-claude-login), Claude Code's own login credential, read at use and never printed or stored.

Unofficial endpoints

list --unofficial and watch --stream use endpoints that are not officially documented. They are opt-in, off by default, and fall back to polling or error cleanly. They may change without notice.

Known limits

  • Verified on a real Mac: release build, tests and send into a real session.
  • Standalone reading with Claude Code's own login is tested against fixtures only and not yet confirmed live.
  • The unofficial endpoints may change without notice.
