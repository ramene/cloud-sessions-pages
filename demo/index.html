Demo (2 minutes)

A script for a 2-minute screen recording.

Prepared: a spare GitHub repo cloned locally and allowed with /cloud-allow, claude trusted in it once, and the plugin installed. Reading uses Claude Code's own login through its RemoteTrigger tool, so no token is needed. One Claude Code session is enough.

TimeDoSay
0:00In the repo, open claude."A cloud session, driven from a normal Claude Code session."
0:10Type /cloud-start Add a build badge to the README and open a pull request."I typed this myself: Claude cannot start or send on its own, and the repo is on my allowlist."
0:25Result shows the title and https://claude.ai/code/session_… link."That ran claude --cloud in a terminal for me."
0:35Type /cloud-watch <link>."Read through Claude Code's own RemoteTrigger tool: its plan, tool calls, results." Let 2–3 events print.
1:00Type /cloud-send <link> Also mention the license in the README."A follow-up goes into the same running session."
1:15Type /cloud-read <link>."My message arrives as an event, then the reply." Point at the user event and the answer.
1:40Type /cloud-track with a link from another session, then /cloud-list."Same core, shown as tasks in the desktop app."
1:55Close on the security line from the README."Token in the keychain, event text treated as data, every send explicit."

Fallback if the cloud is slow: cut the recording at /cloud-read and show the earlier events. Nothing secret is on screen: no token is involved.
