The optional program

A small prebuilt cloud-sessions binary (about 4 MB, MIT licensed, built from crates/ in the repository). The plugin's launcher gets it by itself the first time one of the commands that need it runs:

  • it uses a copy bundled in the plugin if the release has one;
  • otherwise it downloads the release for your computer (macOS universal, Linux x86_64 or arm64) into the plugin's data folder;
  • it checks the SHA-256 against the checksum published with the release before installing it.

It needs only what macOS and Linux already have (curl or wget, tar, and shasum, sha256sum or openssl). If it cannot (offline, release not available), you get one plain sentence and nothing is installed.

Reading, watching and sending never need it.

Only you can start or send

/cloud-start, /cloud-send and /cloud-allow cannot be invoked by the model. See Security.

Standalone CLI and MCP

The program also exposes cloud-sessions start|send|events|watch|list|auth|mcp with JSON output, and an MCP server over stdio. An optional MCP configuration is in extras/mcp.json in the plugin (off by default, so nothing starts or downloads at launch).
