Getting started

Start, track, list, read, watch and send into Claude Code cloud sessions from any Claude Code session. Nothing to install but the plugin: no Rust, no cargo, no Homebrew, no token to paste.

Install (two commands)

claude plugin marketplace add ramene/cloud-sessions
claude plugin install cloud-sessions@cloud-sessions

That is all. Open the repository you want to work on and use the commands in Commands.

To try it from a checkout instead, run claude plugin marketplace add ./, or claude --plugin-dir ./claude-mod/cloud-sessions.

Before your first /cloud-start

  1. Run /cloud-allow in that repository (once per repository).
  2. Make sure claude itself works, and that you have accepted its trust prompt once in that folder. The mod never answers that prompt for you.

What next

  • Start a session: /cloud-start <prompt>. It costs cloud usage, like any other cloud session.
  • Watch it: /cloud-watch <session>.
  • Talk to it: /cloud-send <session> <message>.
  • Read what happened: /cloud-read <session>.

You can also just ask in plain language ("check on my cloud session"): the cloud-sessions skill teaches Claude the same rules.

Optional settings

CLOUD_SESSIONS_DAILY_CAP sets how many sessions you can start per day (default 5).
